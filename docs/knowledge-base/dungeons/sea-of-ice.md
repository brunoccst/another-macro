The wiki has minimaps for maps 1 to 3.

- **T. Black Pearls** are picked up as sparkles, like Black Pearls; as many can be found on a
  map as the Pip count at the map's start. 50 T. Black Pearls upgrade Otohime's Trident.
- **Harpoon fishing** works here. A trap set here takes as long as one set elsewhere.

## Completion rewards

- Class change tome: Sirenaria Tome.
- Badges: Unyielding Bar, Fated Star Fragment.
- All Opuses, Codices and Treatises at 0.1% each per reward slot (22 Opuses = 2.2%, 17 Codices
  = 1.7% per slot on this revision).
- EXP scrolls: High Class Scroll (500,000 EXP), Medium Class Scroll (50,000 EXP).
- One-time award "Searching the Sea of Ice": clear Sea of Ice (Very Hard).

## Fishing pond

- Registered inside the Sea of Ice (Very Hard), with its own completion achievement for every
  fish caught there.
- One shrimp-marked spot, usable once per run, for bait or a trap, with the overworld rules:
  traps take 1-3 h, a sprinkled spot reactivates after 1 h, and the timer can't be skipped by
  starting new runs. A trap placed in one run can be picked up in a later run once its timer
  ends.
- The two Horror fish respawn on every new run, with no 1-hour wait.
