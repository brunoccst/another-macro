# Knowledge base: learned by the project

What the project found out by itself while building, running and testing macros on the phone,
and what the user told it. Facts taken from outside sources (the wiki, Altema) are in
[external/](../external/README.md) instead; the whole knowledge base: [README.md](../README.md).

## Rules

- Say how it was learned and when: "seen on the phone 2026-11-18", "measured on 6 screenshots",
  "the user". A later observation that changes a fact replaces it (keep the date of the new one).
- Measurements behind a threshold or a constant in the code belong here, under the page of the
  map or feature they came from ("What the macro's checks are based on"); the code keeps the
  number and only says what it does.
- `another-macro cat-routes --import` writes the app's survey notes as comments into
  `cat_spots.yaml`; once a spot is checked, move them to
  [cat-scratchbook.md](cat-scratchbook.md#measurements-per-spot).
- Text only, no screenshots of the user's account or other game art.
